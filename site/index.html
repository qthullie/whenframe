Install

pip install git+https://github.com/qthullie/whenframe
whenframe index ~/Videos
whenframe search "the dog jumps into the pool"
whenframe serve

Python 3.10+ and ffmpeg. The first run downloads the model (1.5 GB).

How it works

  • One frame per second, repeated frames skipped, embedded by SigLIP 2 on the CPU.
  • whenframe's own model, trained on more than 100,000 descriptions written by people, rewrites each frame with what the frames around it show: an action, not only a picture.
  • Frames that match almost any text are marked down (query-bank normalisation).
  • Moments of ten seconds around the best frames, ranked across all videos.

The protocol was fixed before each test run, and the criteria it missed are listed with the ones it met.
